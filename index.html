이 기기에서 체크 켜기

체크는 GitHub 저장소 의 data.json에 저장되고, PC가 10분마다 옵시디언 노트에 반영해요. 저장소에 쓸 수 있는 토큰이 필요하고, 토큰은 이 브라우저에만 저장돼요.

  1. 토큰 만들기 페이지를 열어요 (GitHub 로그인 상태)
  2. Token name은 아무거나, Expiration은 원하는 기간으로
  3. Repository access → Only select repositories → game-log
  4. Permissions → Repository permissions → Contents → Read and write
  5. Generate token을 누르고, 나온 토큰을 복사해서 아래에 붙여넣어요
